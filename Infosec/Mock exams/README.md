# IT 323 Midterm Mock Exam Web App

Location: `Documents/Midterms/Infosec`

## What changed
This is now a **functioning local web app**, not just a static viewer.

### Features
- 5 different mock exams
- actual answer textareas for every main question
- local autosave using browser storage
- elapsed timer with pause/resume
- progress tracking per exam
- per-exam reset
- export current exam answers to `.txt`
- print / save as PDF support

## How to use
Open `index.html` in your browser.

## Files
- `index.html` — app shell
- `styles.css` — responsive UI
- `app.js` — mock exam data + app logic

## Notes
- Your answers save in the browser on that machine.
- No backend required.
- If you want a Next.js/React version later, this can be upgraded from here.
